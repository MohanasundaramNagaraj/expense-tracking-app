# 💰 Income & Expense Tracker

A modern, responsive, and user-friendly Income & Expense Tracker web application built using **HTML**, **CSS**, **JavaScript**, and **jQuery**.

This application helps users manage daily income and expenses, track spending habits, generate reports, and export financial data easily.

---

# ✨ Features

## 📊 Dashboard
- Total Income Summary
- Total Expense Summary
- Current Balance Overview
- Monthly Financial Summary
- Recent Transactions
- Interactive Charts

## 💵 Income & Expense Management
- Add Income
- Add Expense
- Edit Transactions
- Delete Transactions
- View Transaction Details

## 🗂️ Category Management
- Add New Categories
- Edit Categories
- Delete Categories
- Default Income & Expense Categories

## 📈 Reports
- Monthly Reports
- Category-wise Reports
- Yearly Summary
- Income vs Expense Analysis
- Filter by Date & Category

## 📤 Export Options
- Export to Excel
- Export to PDF
- Print Reports

## 🌙 Additional Features
- Dark Mode
- Responsive Design
- Mobile Friendly
- Local Storage Support
- Budget Tracking
- Progress Indicators
- Toast Notifications
- Smooth Animations

# 🚀 Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/income-expense-tracker.git
```

## 2️⃣ Open Project Folder

```bash
cd income-expense-tracker
```

## 3️⃣ Run the Project

Simply open:

```bash
index.html
```

in your browser.

✅ No backend or server setup required.
